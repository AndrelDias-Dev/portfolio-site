# Portfólio — Andrel Dias

Site institucional estático, responsivo e otimizado, construído com HTML, CSS e JavaScript puro.

## Como visualizar

Abra `index.html` diretamente ou inicie um servidor local:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Personalização rápida

- WhatsApp e mensagem inicial: edite `CONFIGURACAO` no início de `script.js`.
- Textos e seções: edite `index.html`.
- Cores, espaçamento e animações: ajuste as variáveis no início de `styles.css`.
- Retrato principal: substitua `assets/andrel-dias.webp` mantendo o mesmo nome.

O site respeita a preferência de movimento reduzido do sistema e adapta as interações para telas touch.
